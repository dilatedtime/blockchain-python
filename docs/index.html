PILOT CHAIN
GitHub repository
Python + Flask + Proof of Work

Build, mine, and inspect a blockchain locally.

Pilot Chain is a compact learning project with a Flask node, JSON API, browser wallet, transaction pool, block explorer, peer registration, and longest-valid-chain consensus.

Run the project Read the source

What you can test

Create a wallet

Generate a secp256k1 key pair inside your browser and calculate its balance from confirmed blocks.

Submit transactions

Add sender, recipient, and amount records to the node's pending transaction pool through the UI or API.

Mine blocks

Run a low-difficulty Proof-of-Work loop, receive a one-coin reward, and inspect each block and hash.

Inspect the chain

Review block indexes, timestamps, transactions, nonces, previous hashes, and the complete JSON response.

Connect peers

Register node URLs and compare chains across multiple locally running Flask processes.

Resolve conflicts

Adopt a longer peer chain after validating its previous hashes and Proof-of-Work results.

Run it in a few commands

The live blockchain needs Python. This GitHub Pages site is a static project overview.

git clone https://github.com/dilatedtime/blockchain-python.git
cd blockchain-python
python -m venv venv

# Activate the environment, then:
pip install -r requirements.txt
python node_server.py

# Open http://127.0.0.1:5000

Built for learning

State is stored in memory and resets when the server stops. The node does not verify the browser-generated transaction signatures yet. Use Pilot Chain for local experiments, not real assets or payments.
